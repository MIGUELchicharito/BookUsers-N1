# BookUsers · Parcial Final POO 2026B (Grupo N1)

Aplicación de escritorio en Java 21 y Java Swing para el registro, consulta y exportación a PDF de usuarios compartiendo una única lista `ArrayList<Usuario>`.

## Requisitos
- **JDK 21** configurado en IntelliJ IDEA (`File → Project Structure → Project → SDK`).
- Plugin **Swing UI Designer** habilitado en IntelliJ IDEA.
- Librería **OpenPDF** incluida en la carpeta `lib/` del repositorio.

## Cómo ejecutar el programa
1. Clonar el repositorio y cambiar a la rama `UlloaMiguel`.
2. Abrir la carpeta `BookUsers-N1` en **IntelliJ IDEA**.
3. Verificar que el **Project SDK** sea **JDK 21** y que la librería en `lib/openpdf-1.3.39.jar` esté cargada en `Project Structure → Libraries`.
4. Abrir `src/FormMenu.java` y ejecutar el método `main`.
